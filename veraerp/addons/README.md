# Addons

Keep all veraERP customizations in separate Odoo addons.

- `veraerp_branding`: white-label UI, login screen, email branding
- `veraerp_tenant`: tenant records, domain mapping, isolation rules
- `veraerp_billing`: plans, Stripe integration, invoices, renewals
- `veraerp_provisioning`: template DB cloning, tenant creation, teardown
